Low-Level Computer Science, Systems Programming, and Security Resource Roadmap

Overview & Two Practical Caveats

This guide synthesizes a structured learning curriculum spanning foundational computer science, C and C++ systems programming, x86-64 assembly, Application Binary Interfaces (ABIs), operating system internals, microarchitectural performance tuning, and reverse engineering with binary exploitation. Every section pairs analytical context and architectural trade-offs with categorized links—covering official specifications, open textbooks, interactive labs, developer tools, and both English and Arabic courses or videos where available in each domain.

Note

Documentation on roadmap.sh varies in editorial vetting: official tracks undergo multi-stage review cycles with subject-matter experts according to roadmap.sh staff (though experienced C practitioners still critique omissions in draft layouts), whereas community-contributed roadmaps are explicitly marked as unverified by the platform
